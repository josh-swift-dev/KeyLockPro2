Help using KeyLockPro2

Need help with KeyLockPro2? Use the information below or contact support directly.

Getting Started

When you first open KeyLockPro2, create a master password. Your master password protects access to your encrypted vault.

Choose a strong password or passphrase that you can remember. KeyLockPro2 cannot recover a forgotten master password for you.

Adding a Password

From the Home screen, tap the + button to add a login.

You can save information including:

  • Login name or title
  • Username
  • Password
  • Website
  • Notes
  • Group
  • Favorite status

Groups

Groups help organize your passwords.

You can create a new group while adding or editing a login. Groups automatically appear on the Home screen.

Password Generator

Tap Password Generator in the bottom navigation bar to create a strong random password.

You can customize the password length and choose whether the password includes uppercase letters, lowercase letters, numbers, and symbols.

Password Health

KeyLockPro2 can locally identify potentially weak or reused passwords. These checks are performed using information stored in your local vault.

Face ID

If your device supports Face ID, you can enable biometric unlocking from Settings.

Face ID provides a convenient way to unlock KeyLockPro2 while your master password remains the primary credential protecting the vault.

Auto-Lock

KeyLockPro2 can automatically lock after you leave the app. You can configure the auto-lock delay from Settings.

Copying Passwords

When you copy a username or password, KeyLockPro2 places the information on the device clipboard temporarily.

You can choose how quickly copied credential information expires from the clipboard in Settings.

Encrypted Backups

KeyLockPro2 allows you to export an encrypted backup of your vault.

The backup uses the KeyLockPro2 master password that was active when the backup was created.

The exported backup does not contain your passwords as an unencrypted plain-text password list.

Changing Your Master Password

You can change your master password from Settings.

Important: changing your master password does not change the password protecting backup files that were created earlier.

An older backup still requires the master password that was being used when that backup was created.

Importing a Backup

Open Settings and select the encrypted backup import option. Choose your KeyLockPro2 backup file and enter the master password that was used when the backup was created.

Recently Deleted

Deleted passwords are moved to Recently Deleted rather than being immediately destroyed.

You can restore a deleted password during the recovery period or permanently delete it sooner.

I Forgot My Master Password

KeyLockPro2 does not store a recoverable copy of your master password. The developer cannot retrieve or reset the password for your existing vault.

If you cannot remember the password, use Forgot Master Password? Start Over from the locked screen.

Warning: starting over permanently erases the local KeyLockPro2 vault and its local encryption key.

Previously exported encrypted backup files are not deleted when you start over.

Theme

KeyLockPro2 supports System, Light, and Dark appearance options. You can select your preferred appearance from Settings.
